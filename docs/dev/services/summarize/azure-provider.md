# Planned Azure provider

Azure is folium's first planned hosted provider path for the summarization
service. It is retained as a configuration direction, not a supported runtime
option or a claim about production data handling.

Before an Azure provider is enabled, its identity, network, data-residency,
cost, and validation requirements must be implemented and documented.

See [deployment modes](../../architecture/deployment-modes.md) and
[deployment order](../../architecture/deployment-order.md) for context.
