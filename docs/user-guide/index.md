# Help Center

These guides are for people using folium day to day. Whether you are catching up
on a patient's recent encounter notes, checking a voice-note transcript, or
reviewing the records available for an interaction, start with the task in front
of you.

## Start with the task at hand

- [Patients and encounters](patients-and-interactions.md) to look through a
  patient's recent notes and available context, then add or review an
  interaction.
- [Capture a voice note](voice-notes.md) to record, process, and check a
  transcript before using it as context.
- [Request a chart-review draft](chart-review.md) when a clinician wants help
  organizing the available context for a selected interaction.
- [Review states, citations, and flags](lifecycle-citations-and-flags.md) to
  understand what the draft shows and what still needs attention.

Folium supports clinician review at every step. It is not a complete EHR or a
production clinical system: it does not use real patient data, diagnose,
recommend treatment, or take autonomous action.
