# Azure infrastructure

This directory contains the Azure configuration being retained for folium's
planned hosted full-stack deployment. Azure is the first planned hosted target
after the local/on-prem workflow is implemented and validated.

It is not a supported default deployment path. Any Azure implementation must
make identity, networking, data residency, and operational-cost decisions
explicit before it is presented as a product capability.

See the [deployment modes](../../docs/dev/architecture/deployment-modes.md) and
[deployment order](../../docs/dev/architecture/deployment-order.md) for context.
