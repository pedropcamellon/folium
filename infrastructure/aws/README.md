# AWS infrastructure

This directory contains the AWS configuration being retained for folium's
planned hosted full-stack deployment. AWS follows Azure in the deployment order
after a hosted path is implemented and validated.

It is not a supported default deployment path. Any AWS implementation must
make identity, networking, data residency, provider cost, and operational
visibility explicit before it is presented as a product capability.

See the [deployment modes](../../docs/dev/architecture/deployment-modes.md) and
[deployment order](../../docs/dev/architecture/deployment-order.md) for context.
